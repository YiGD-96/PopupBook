# 2p 가게 웹진(세부 페이지) 규격

`src/WebzineBook.tsx` · `src/webzine.ts` · `src/cinematic.css`(「The shops' web-magazine pages」 구간). 글꼴은 Pretendard Variable.

## 종이 크기
- 웹: 가로 `min(1500px, 95vw, (100svh − 118px) × 1.608)`, 세로는 가로 ÷ 1.608 (가로:세로 = 836:520). 한 장은 두 쪽(왼/오).
- 모든 크기의 기준 단위 `u` = 종이 가로 ÷ 1672 → 창 크기가 바뀌어도 한 장의 그림처럼 같이 커지고 작아짐. 종이 안 여백: 위 40u · 좌우 56u · 아래 32u, 머리띠 34u(+아래 26u), 쪽 사이 46u.
- 폰(≤760px): 가로 = 화면 − 16px, 세로 고정 없음(위에서 아래로 스크롤, 최대 높이 100svh − 76px), 두 쪽이 위아래로 쌓임. 여백 18px · 아래 30px. 맨 아래에 "이전 쪽 / 다음 쪽으로(마지막은 이야기 닫기)" 버튼.

## 글자 5종류
| 역할 | 웹 (u → 책 폭 1180px일 때) | 폰 | 굵기 | 쓰이는 곳 |
|---|---|---|---|---|
| 제목 | 53.8u → 약 38px | 27px | 800, 행간 1.26 | 큰 제목 |
| 부제목 | 34u → 약 24px | 21px | 800, 행간 1.32 | `01.` `02.` `03.` 섹션 제목 |
| 소제목 | 27u → 약 19px | 17px | 제목 아래 한 줄 소개 500 · 나머지 700~800 | 제목 아래 소개, 첫 문단 위 굵은 줄, 메뉴 이름, 사진 설명 제목 |
| 본문 | 22.7u → 약 16px | 15px | 보통, 행간 1.6(폰 1.7) | 모든 문단, 메뉴·사진 설명, 맨 위 띠 |
| 강조글 | 25.5u → 약 18px | 17px + 2pt | 600 기울임, 주황 `#a35c2d`, 행간 1.7 | 인용문 |
- 간격: 블록 사이 22u(폰 16px), 강조글 위아래 36u(폰 24px). 인용문 앞 들여쓰기 24u(폰 20px).
- 5종류 밖: 아래쪽 쪽 넘김 막대(13px, 종이 밖).

## 사진 비율
- 웹: 큰 사진 가로 100% · 1.86:1, 사진+글 `portrait` 43% · 0.62:1 / `wide` 62% · 1.38:1 / `natural` 54% · 원본, 메뉴 `wide` 46% · 원본 / `tall` 42% · 0.75:1 / `natural` 31% · 원본 / `compact` 50% · 2.2:1.
- 폰: 모든 사진 원본 비율(자르지 않음).
